# Dataset Fetching Guide

## Finding a Dataset

1. Go to [Roboflow Universe](https://universe.roboflow.com/)
2. Search for the dataset you need
3. Select the dataset that best matches your use case
   > Tip: Check the sample images to confirm they are similar to your own data

## Downloading the Dataset

1. On the dataset page, click **Dataset** in the left sidebar
2. Select the desired **version**
3. Choose the download format matching your model (`YOLOv8` or `YOLOv26`)
4. Click **Download Dataset**
5. Select **"Download zip to computer"** and confirm

## Adding the Dataset to the Project

1. Extract the downloaded `.zip` file
2. Move the extracted folder into the `datasets/` directory of this project
